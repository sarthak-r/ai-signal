Astral shipped Ruff v0.16.0 with 413 rules enabled by default, up from 59 — the default set had barely moved since 2023. The additions catch severe problems that previously passed silently, including syntax errors and immediate runtime errors like yield-in-init and load-before-global-declaration. Simon Willison's workflow for the upgrade: run uvx ruff@latest check . --fix --unsafe-fixes, then hand the violations Ruff can't auto-fix to a coding agent to clear. He ran it against three large projects and each surfaced hundreds of real violations.

If your Python CI pins Ruff, a bump to 0.16 will light up — schedule it rather than letting it ambush a release. The remediation pattern is the transferable part: a deterministic tool finds and auto-fixes the mechanical cases, and the agent only touches the residue that needs judgement, which keeps both the token bill and the review surface small. Cheap tool first, model on the remainder, is the right default for any lint, migration or codemod job.

Ship Log

The Opus 5 API changes that matter more than the benchmarks, and Claude Code lets subagents nest.

Claude Opus 5: swap an agent's tools mid-run without busting the cacheanthropic.com · 24 Jul

The Opus 5 launch is the window's big frontier drop, priced unchanged at $5/$25 per MTok. Two API changes matter more to agent builders than the benchmark line. First, you can add or remove tools mid-conversation without invalidating the prompt cache; previously any change to the tool set forced a cold cache and a full re-bill of the context. Second, requests that a safety classifier flags can be set to route to another model instead of returning a hard error, so a flagged call yields a result rather than a 4xx your code has to catch. There's also an effort setting to trade intelligence for token savings. On Anthropic's own numbers it more than doubles Opus 4.8 on Frontier-Bench and beats Fable 5 on OSWorld at a third of the cost.

The cache-preserving tool swap changes how you architect a long agent session. You no longer fix the tool list up front or eat a cold cache each time the task moves to a new phase, so narrow, phase-specific toolsets become cheap instead of costly. The safety fallback removes a class of production incident: a classifier false-positive that used to surface as an error now degrades to a different model quietly. Both are free wins if you're already on Opus, and neither shows up in a benchmark.

Claude Code 2.1.219: subagents can spawn subagents, three deepcode.claude.com · 24–25 Jul

Claude Code raised the default subagent nesting depth from 1 to 3 (CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 restores the old limit), so an orchestrating agent can fan out into sub-orchestrators within a single run. The same release added a DirectoryAdded hook that fires when /add-dir or the SDK registers a new working directory mid-session, and a sandbox.network.strictAllowlist setting that denies non-allowlisted hosts outright with no prompt. Opus 5 is now the default Opus model in Claude Code, with a 1M-context fast mode at $10/$50 per MTok. 2.1.220 followed a day later with fixes.

Depth-3 nesting turns Claude Code from one agent with helpers into a small tree, which is the difference between "summarise these ten files" and "audit this subsystem, delegating each module." The strict allowlist is the quietly important one for your context: it's a real primitive for running agent-generated code in CI without a network escape, the exact failure mode that put a runaway agent in this briefing twice last week. Pair it with the DirectoryAdded hook to enforce policy the moment a new repo root enters a session.

Build Patterns

Two shipped answers to old problems: an LLM on your database without the rows, and voice as the way you watch a run.

FluentDB: give an LLM your schema, not your rowsProduct Hunt · 25 Jul

FluentDB, the #2 launch on Product Hunt on 25 July (288 points), is an AI database client for Postgres, MySQL, SQLite and SQL Server built on one rule: "models see your schema, not your data." The model gets table and column structure to write queries and never sees rows. AI-generated queries also require explicit human approval before they run, by default.

Copy the pattern whether or not you use the product. The reason teams hesitate to point an LLM at a production database is exfiltration — a prompt injection or an over-broad query pulling client records into a model context — and schema-only access closes most of that hole while keeping the useful part, since query generation needs structure, not contents. Approval-before-execute is the second half: the model proposes, a human commits. For a wealthtech product sitting on client financials, "the model never saw a row" is a sentence you want to be able to say to an auditor.

AUSTRAC compliance-officer notification is due 29 Julyaustrac / namescan · 3 days out

Tranche 2 entities brought into Australia's AML/CTF regime on 1 July 2026 — accountants, lawyers, conveyancers and real-estate agents, alongside virtual-asset providers — must notify AUSTRAC of their appointed AML/CTF compliance officer by the later of 29 July 2026 or 14 days after enrolment. AUSTRAC is explicit that this is separate from enrolment: registering the business does not satisfy the compliance-officer notification.

This lands on your customers rather than on you, which is the opportunity. A meaningful share of advice practices and their accounting and legal partners are newly in scope and three days from a hard date many won't have flagged. A dated in-product nudge, or a one-line reminder in your next customer comms, is the kind of thing that earns an advisory firm's trust for the harder compliance work later. Know the date before your customers ask.

DeepSeek's legacy API aliases stopped resolvingapi-docs.deepseek.com · 24 Jul

At 15:59 UTC on 24 July, DeepSeek hard-retired the deepseek-chat and deepseek-reasoner model names with no grace period. Both were routing labels silently forwarding to V4; calls to the old strings now return HTTP errors. The migration targets are deepseek-v4-flash (the new default) and deepseek-v4-pro (reasoning, 1M context).

The failure mode is the nasty kind: an alias that worked for months returns a 4xx the day a dependency's config still pins it. Grep your stack, and your tooling configs, for the old names — a Claude Code or agent-framework preset that hard-codes deepseek-chat breaks without warning. The wider lesson is to pin concrete model versions, not convenience aliases, so a vendor's routing change is your decision to make rather than an outage you find in production.
