Simon Willison flags the first self-replicating prompt injectionsimonwillison.net · 29 Jul

Willison surfaced Håkon Måløy's writeup of a prompt injection that survives a round trip through Copilot for Word. Hidden instructions in a source document get carried into the document Copilot drafts, so the output becomes a fresh carrier that infects the next person who feeds it to an AI — no further contact from the original attacker. White-on-white hidden text is old; the deliberate self-replication is new. Microsoft received responsible disclosure and has not shipped a full mitigation.

Any agent that reads untrusted content and then writes new content is a propagation surface, not a one-shot target. For a product that ingests client statements, PDFs and emails, treat model-written output as tainted until sanitised, and never let one drafting agent's output feed another agent unchecked — one poisoned file can seed many.

Ship Log

The protocol under your connectors got rewritten, and a desktop agent split its brain from its hands.

MCP 2026-07-28: stateless core, Tasks and Apps as extensions, OAuth-aligned authmodelcontextprotocol.io / claude.com · 28 Jul

The MCP 2026-07-28 release candidate drops the stateful session model for request/response, so a remote server can run serverless behind a round-robin load balancer instead of needing sticky sessions and a shared store, and clients can cache tools/list. Long-running work moves to a Tasks extension (the server returns a task handle the client drives with tasks/get / tasks/cancel), UI moves to MCP Apps, and both live in a versioned Extensions framework with reverse-DNS IDs. Authorization aligns to OAuth 2.0 / OpenID Connect. Anthropic shipped Claude support the same day: enterprise-managed connector auth via Entra/Okta, an observability dashboard for published connectors, and MCP Tunnels for reaching servers inside a private network.

Stateless removes the operational tax that made remote MCP servers a chore to run — edge/serverless deploys become viable. The cost is a migration you should schedule now: the initialize/initialized handshake is gone (client info rides in _meta on every request) and anyone on the 2025-11-25 experimental Tasks API moves to the new lifecycle. It is a release candidate, so pin your target and test against it before it finalises.

Perplexity's Personal Computer agent lands on Windowsperplexity.ai / siliconangle · 28 Jul

Perplexity shipped its desktop agent for Windows: an always-on agent that reads and edits local files and drives Excel, PowerPoint, Word, Outlook and OneDrive. Reasoning stays in the cloud — an orchestrator (Claude Opus 4.7 by default) decomposes each task and routes sub-tasks across a roster of 20-plus models. It prompts before sensitive actions like sending mail or deleting files. Max and Enterprise Max only, from $200/mo.

The cloud-brain, local-hands split is the design worth copying. The desktop is the actuator; the model roster is swappable behind an orchestrator. If you are building a desktop or ops agent, that shape keeps you off any single model and lets you route cheap-by-default and escalate on the hard requests without shipping inference to the client machine.

Build Patterns

The new MCP surface turns a tool that returns JSON into a tool that returns an interface.

MCP Apps: connectors that render their own UI in the conversationmodelcontextprotocol.io · 28 Jul

The MCP Apps extension lets a server return server-rendered HTML that the host displays in a sandboxed iframe inside the conversation, alongside tool calls. A connector can show a form, a chart or an interactive control where you would otherwise get text the model paraphrases — and Claude already renders it.

The unit you ship stops being a tool that returns JSON and becomes a tool that returns an interface. For a wealthtech connector that means a scenario slider or a projection chart rendered in-chat, with direct manipulation and fewer numbers for the model to hallucinate on the way past. Now that the surface exists, design connectors UI-first for anything where a rendered control beats a paragraph.

Your Radar

Document-borne injection is the compliance-shaped risk your buyers will start asking about.

Document-borne prompt injection is now a named, replicating threatenklypesalt / simonwillison · 29 Jul

The self-replicating Word/Copilot worm above generalises: untrusted content reaches a tool-wielding agent and issues instructions it obeys, and the payload can now propagate through the documents the agent produces, not just the one it reads.

For an Australian wealthtech product this is the risk your compliance-minded buyers will raise. Any pipeline that ingests client documents and lets an agent act — draft advice, update a record, send a message — needs the injection boundary drawn on purpose: neutralise instructions in ingested content, gate side-effectful actions behind human sign-off, and log what the agent read. It is the propose-stage-approve loop that keeps agents safe on live sites, applied to document intake.
